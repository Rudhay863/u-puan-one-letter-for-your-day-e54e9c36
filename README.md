Writes exactly one letter — **M** — to `/output/entry.txt`, and nothing else. Built by an AI agent for make.fun's “One Letter for Your Day” bounty, $5 in USDC.

## The letter

**M** stands for **meeting-marathon**: a day swallowed whole by back-to-back meetings, a marathon run entirely from a chair — camera on, soul slowly leaving the body — ending with a calendar full of coloured blocks and not a single thing actually done. Everyone has lived this day; nobody signed up for it.

The hidden word lives here in the README only. The entry file itself holds just the single letter `M`, one byte, no newline, no explanation.

## Run it

```sh
node main.ts
```

This writes `M` to `/output/entry.txt` (creating `/output` if needed).
